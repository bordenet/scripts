# Narrated demo video

Identify the audience, what they should learn, and what they can see that
supports it. Use the supplied slides or recordings, or capture an authorized
test workflow. Ask for missing inputs only when their absence prevents an
accurate or shareable cut.

## Establish what the footage shows

- For a walkthrough, verify the steps and result in the recording or runnable
  build. Label prototypes, simulations, and test environments when they appear.
  Describe production availability only when separately verified.
- For a comparison, use the same action, role, and comparable sample data in
  both clips. If one version cannot be verified, deliver a walkthrough of the
  available version and explain the gap in the handoff.
- For a slide presentation, confirm the talking points against the supplied
  material. Keep confidential speaker notes, hidden slides, and presenter
  view out of the recording.

## Prepare footage and narration

Work in a private folder outside version control. Use a clean profile,
disable notifications, and record only the intended window. Prefer synthetic
data and read-only actions. Perform writes only in an authorized test
environment. Keep originals and production notes private.

Make a short sequence that introduces the goal, shows the relevant action or
slide, and ends with a result the visuals support. Preserve meaningful waits
and action order. Mark any time jump that could change what viewers infer.
Write narration that adds context to what's visible and leave time for viewers
to read captions and interface text.

Use a local recording, locally generated speech from an authorized voice, or
timed text. Get authorization for any hosted narration service, including
the text it will receive and any charges. Check that each asset and voice
is cleared for the intended use and audience. Use original or synthetic
media where rights are unclear.

## Export and hand off

Follow the [production guide](references/production.md) for editing, captions,
and local export. Watch the finished MP4 with sound and muted. Check the
picture, audio, captions, and metadata for private or unlicensed material.
Fix any disclosure and review the new export before handoff.

Return the checked MP4, narration text, and the caption file if captions are
separate. If the final cut is blocked, explain what's missing and include any
draft materials that pass the same privacy and rights checks. Get separate
authorization before uploading or sending the deliverables.
